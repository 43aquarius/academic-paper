\begin{itemize}[leftmargin=1.6em, itemsep=0.55em]
\item A model-free, training-free selector compresses long contexts in milliseconds.
\item Three-dataset, 1600-record study maps the accuracy--compression--cost frontier.
\item BM25 leads raw recall; the positional prior trades recall for reader-side placement.
\item A measured GPT-2 perplexity gate costs 255--320$\times$ more compute for less recall.
\item Evidence recall correlates only weakly with end-task answer accuracy.
\end{itemize}
