# 图表选型说明（按《实验绘图推荐》prompt 流程产出）

角色：顶会数据可视化专家。以下为每张实验图的选型理由与视觉规范。

## Figure 2 — 压缩比-质量权衡曲线
- 推荐方案：带置信区间的折线图（趋势与收敛类 #6）
- 核心理由：核心叙事是"压缩比增大时质量如何衰减"，Sieve 与 Head/Random/TextRank
  的差距随 r 放大；折线是衰减趋势的最直接表达，CI 阴影区满足统计严谨性要求
- 坐标轴：X = 压缩比 r（2/4/8，对数刻度），Y = token-level F1（%）
- 尺度处理：r 跨越数量级 → X 轴对数刻度（log2）
- 统计要素：bootstrap 95% CI 半透明阴影
- 配色：Okabe-Ito（Sieve=蓝 #0072B2 实线加粗，Head=橙 #E69F00，Random=灰虚线，
  TextRank=绿 #009E73 点划线）；线型区分保证灰度可读

## Figure 3 — 位置偏置分析
- 推荐方案：折线图（数据关系类）+ 参考线
- 核心理由：验证"lost in the middle"（U形）以支撑位置先验设计；X = 证据句相对位置
  （0/25/50/75/100%），Y = EM/F1；期望呈 U 形
- 统计要素：bootstrap 95% CI 阴影

## Figure 4 — 压缩开销对比
- 推荐方案：双对数折线图（趋势类）
- 核心理由：压缩耗时随上下文长度的扩展性；同时画出 perplexity 门控的解析下界
  （GPT-2 前向 FLOPs 换算），形成 3-4 个数量级的对比叙事
- 坐标轴：X = 上下文词数（log2），Y = 单次压缩耗时 ms（log10）
- 尺度处理：跨数量级 → 对数坐标（推荐方案 b）
